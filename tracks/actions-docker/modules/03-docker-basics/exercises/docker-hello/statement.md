Cài Docker theo tab **Cài đặt** của track, rồi chạy:

```bash
docker run hello-world
```

Chụp màn hình terminal có dòng `Hello from Docker!` và gửi vào kênh Discord của track **trước buổi online đầu tiên**. Mentor dùng danh sách này để biết ai cần giúp cài đặt ở đầu buổi.

Sau đó thử các lệnh của bài "Chạy, xem, vào trong, dọn dẹp" và đánh dấu từng mục khi xong.

<details>
<summary>Gợi ý nếu bị lỗi</summary>

- `WSL 2 installation is incomplete` hoặc `Virtualization support not detected`: xem mục "Khi bị lỗi" ở tab **Cài đặt** (bật WSL2 và ảo hóa trong BIOS).
- `Cannot connect to the Docker daemon`: mở Docker Desktop và chờ nó khởi động xong.
- Máy không cài được: dùng GitHub Codespaces (tab **Cài đặt**), chụp màn hình terminal trong Codespaces cũng được.

</details>
