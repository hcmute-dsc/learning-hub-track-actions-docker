## GitHub Actions

- [GitHub Actions documentation](https://docs.github.com/en/actions): tài liệu chính thức.
- [Workflow syntax](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax): tra cứu mọi khoá trong file workflow.
- [Using custom workflows with GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages): deploy Pages bằng Actions.
- [Secure use reference](https://docs.github.com/en/actions/reference/security/secure-use): permissions, secret, script injection, `pull_request_target`.
- [actionlint](https://github.com/rhysd/actionlint): kiểm tra file workflow trên máy.
- [lychee](https://github.com/lycheeverse/lychee) và [lychee-action](https://github.com/lycheeverse/lychee-action): công cụ kiểm tra link hỏng.

## Docker

- [Docker docs: Get started](https://docs.docker.com/get-started/): tài liệu nhập môn chính thức.
- [Dockerfile reference](https://docs.docker.com/reference/dockerfile/): mọi lệnh trong Dockerfile.
- [Docker build cache](https://docs.docker.com/build/cache/): layer và cache, giải thích kỹ hơn chương 4.
- [Volumes](https://docs.docker.com/engine/storage/volumes/) và [Networking](https://docs.docker.com/engine/network/): chương 5.
- [Compose file reference](https://docs.docker.com/reference/compose-file/): mọi khoá trong `compose.yaml`.
- Trang image chính thức trên Docker Hub: [nginx](https://hub.docker.com/_/nginx), [postgres](https://hub.docker.com/_/postgres) (biến môi trường, thư mục dữ liệu).
